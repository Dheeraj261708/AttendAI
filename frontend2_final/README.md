# AttendAI Frontend 2

Clean React/Vite frontend for the AI Attendance Management System.

## Run

```powershell
npm install
npm run dev
```

Open `http://localhost:5173`.

## API

Optional `.env`:

`VITE_API_URL=http://localhost:5000/api`

Authentication expects `POST /auth/login` and `POST /auth/register` under that API base.
